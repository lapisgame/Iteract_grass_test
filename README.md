# 🌱 AI Garden Assistant

Интеллектуальный анализ условий выращивания растений с использованием машинного обучения и AI моделей.

## 🚀 Быстрый старт

### 1. Запуск фронтенда

```bash
# Запускаем простой веб-сервер
python3 -m http.server 8000
```

Откройте в браузере: **http://localhost:8000**

### 2. Запуск локального ML backend (рекомендуется)

```bash
# Запускаем ML сервер
./start-backend.sh - не функционально

# Ручной запуск
cd backend/
source venv/bin/activate
python3 -c "import uvicorn; uvicorn.run('server:app', host='127.0.0.1', port=8001)"
```

ML backend будет доступен на **http://localhost:8001**

## 🤖 Доступные AI модели

### 1. **Локальная ML модель** (рекомендуется) ⭐
- Использует обученные модели: **XGBoost** + **Random Forest**
- Работает **без интернета**
- **Не требует API ключей**
- Быстрая и точная
- Требует запуска backend сервера

**Как использовать:**
1. Запустите `./start-backend.sh`
2. В приложении выберите модель "Локальная ML модель"
3. Нажмите "Анализировать условия"

### 2. **Google Gemini**
- Мощная облачная модель от Google
- Требует API ключ (бесплатно)
- Получить ключ: https://aistudio.google.com/app/apikey

### 3. **Cohere Command**
- Облачная модель с бесплатным тарифом
- Требует API ключ
- Получить ключ: https://dashboard.cohere.com/api-keys

## ⚙️ Настройка API ключей

Отредактируйте файл `config.js` для облачных моделей.

## 📊 Параметры для анализа

1. **Влажность почвы** (%) - оптимально: 50-70%
2. **Освещенность** (ч/день) - оптимально: 6-8 ч/день
3. **pH почвы** - оптимально: 6.0-7.0
4. **Температура воздуха** (°C) - оптимально: 20-25°C
5. **Температура почвы** (°C) - оптимально: 18-22°C
6. **Азот (N)** (мг/кг) - оптимально: 70-100 мг/кг
7. **Фосфор (P)** (мг/кг) - оптимально: 50-70 мг/кг
8. **Калий (K)** (мг/кг) - оптимально: 80-110 мг/кг
